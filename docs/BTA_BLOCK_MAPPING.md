# Better than Adventure → Java 26.3: block mapping

Every BTA 8.0.1 block with metadata 0 and, for painted blocks and wool, the result for each colour,
with the default palette. The table is generated from the code: `python -m worldbridge.bta.blockmap`
prints it.

The woods chosen for painted wood can be changed with a palette file (`--bta-palette`, example in
`worldbridge/bta/data/palette.example.properties`). Properties that depend on neighbours (stair
shapes, fence and pane connections, redstone wire, leaf distance, snowy grass, note block
instruments, double chests) are recomputed after the mapping with Minecraft 26.3's rules.
